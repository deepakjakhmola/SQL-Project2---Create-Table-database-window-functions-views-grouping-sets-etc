# **SQL Project: Employee and Department Management**

## **Overview**
This project involves creating, managing, and analyzing employee and department data using SQL. It includes tasks on table creation, data modification, and advanced queries.

---

## **Tasks Overview**

1. **Table Creation**
   - Create `employees` and `departments` tables with `NOT NULL` constraints.

2. **Table Alteration**
   - Add constraints, rename columns, and set default values.

3. **Data Insertion**
   - Insert records into tables and resolve constraint errors.

4. **Data Updates**
   - Update employee positions, salaries, and titles.

5. **Advanced Queries**
   - Create a view `v_employees_info` with manager and activity status.
   - Calculate average salaries and perform salary adjustments.

6. **Complex Analysis**
   - Perform ranking, aggregations, and running totals.
   - Answer advanced SQL questions, e.g., top earners and salary trends.

---

## **Key SQL Skills**
- Table creation and constraints.
- Data updates and error handling.
- Advanced queries (window functions, views).
- Aggregations and hierarchical analysis.
